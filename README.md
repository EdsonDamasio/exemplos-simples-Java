# Exemplos básicos em Java ☕

```java
System.out.println("Olá mundo!");
```

Este repositório contém uma lista de **exemplos simples desenvolvidos em Java**, criados com o objetivo de estudar a **sintaxe da linguagem** e praticar alguns de seus **conceitos básicos**.

Os exemplos são pequenos e diretos, permitindo entender como determinadas instruções funcionam antes de avançar para conceitos mais complexos.

---

## 📚 Exemplos

A lista de exemplos inclui:

### 1. Lista de números (no codigo é feita analogia de terras para ficar mais entretido)

Neste exemplo, são utilizados números dentro do `System.out.println()` para realizar operações matemáticas básicas.

O objetivo é entender como o Java trabalha com valores numéricos e como podemos realizar operações utilizando esses valores.


### 2. Declaração Simples

Neste exemplo, é utilizado o `System.out.print()` para imprimir duas mensagens na tela.

A principal diferença é que as mensagens permanecem **na mesma linha**, já que o `print()` não adiciona uma quebra de linha automaticamente.


### 3. Utilizando números

Neste exemplo, são realizadas **operações matemáticas básicas** utilizando o `System.out.println()`.


O objetivo é praticar operações básicas com números diretamente dentro do `println()`.

# ▶️ Como executar os exemplos

Para executar os códigos deste repositório, você precisará dos seguintes programas:

* [Java JDK]
* [IntelliJ IDEA]
* Este repositório/classe Java com os exemplos

> **Importante:** o IntelliJ IDEA precisa de um **JDK configurado** para criar e executar aplicações Java. Caso você ainda não tenha um JDK configurado, o próprio IntelliJ pode oferecer a opção de baixar um durante a criação do projeto.

---

## 1. Instale o IntelliJ IDEA

Baixe e instale o IntelliJ IDEA pelo site oficial da JetBrains:

[Baixar IntelliJ IDEA](https://www.jetbrains.com/idea/download/?utm_)

Depois de instalar, abra o programa.

# 📂 Executando os exemplos deste repositório

Se você já baixou ou clonou este repositório, o processo é ainda mais simples.

### 1. Abra o projeto

No IntelliJ IDEA, selecione:

```text
File
→ Open
```

Depois, escolha a pasta onde o repositório está localizado.

---

### 2. Encontre os arquivos `.java`

localizado em ambas pastas e no arquivo src 


### 3. Abra o exemplo que deseja executar

Clique duas vezes no arquivo `.java`.

Por exemplo:

```text
Terras.java
```

---

### 4. Execute o arquivo

Com o arquivo aberto:

1. Clique no botão **▶** próximo ao método `main`.
2. Selecione a opção de execução.
3. Aguarde o IntelliJ compilar o programa.
4. Confira o resultado na janela **Run**.

e pronto! os codigos cada um vão executar!
